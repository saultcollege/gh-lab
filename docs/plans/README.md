- Files stored here record planned work. 
- Each file corresponds to a broader group of related tasks.
- The `Status` heading at the top of each file indicates the current status of that plan and may be one of
  - `TODO` (the plan is not being actively worked on but exists as a record of future planned changes)
  - `ACTIVE` (the individual tasks within the plan are currently being worked on)
  - `DONE` (the plan has been implemented and remains as a record of past changes)
- Plan files start as an initial rough sketch of the plan as a `TODO`. 
- A plan file in `TODO` may be updated to record design decisions and a final set of tasks.
- Tasks should be listed numerically with a checkbox following the item number.  E.g.
  1. [+] This task has been completed
  2. [-] This task is being actively implemented
  3. [ ] This task still needs to be done and is not being actively implemented
- A plan may be set to `ACTIVE` once the set of tasks has been finalized
- Once all tasks have been completed the plan can be set to `DONE`
